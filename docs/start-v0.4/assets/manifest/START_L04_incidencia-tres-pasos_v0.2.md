## Incidencia
La v0.1 anuncia una práctica de tres pasos, pero mostraba solo dos bloques: BORRADOR y MEJORA.

## Corrección candidata v0.2
1. REVISA EL BORRADOR: lee el resultado y detecta qué falta.
2. PIDE UNA MEJORA: solicita un cambio claro y concreto.
3. COMPRUEBA Y ELIGE: verifica lo importante y conserva la versión útil.

Original editable SVG y exportaciones PNG y WebP de 1600 × 900. La v0.1 se conserva como antecedente, con estado DESCARTADO para publicación.
