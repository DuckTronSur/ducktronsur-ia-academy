## Reglas

- No marcar un recurso como disponible hasta revisar el archivo final.
- Conservar el original y la exportación usada por el Campus.
- No incluir nombres, correos, teléfonos, contraseñas, tokens ni datos de terceros.
- Verificar que las capturas muestran una interfaz vigente antes de aprobarlas.
- Registrar dimensiones, formato, tamaño y texto alternativo cuando se incorporen.
