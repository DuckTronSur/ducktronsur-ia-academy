# Pendientes y límites de publicación — START v0.4

Todos los recursos de este paquete son candidatos, no material publicado.

## L01 — PENDIENTE
- fichas verificadas de herramientas
- glosario visual detallado
- demostración con capturas reales

## L02 — PENDIENTE
- capturas accesibles de interfaz
- comparativa móvil / ordenador de servicio real
- demostración de voz y adjuntos

## L03 — PENDIENTE
- actividad editable avanzada
- capturas actuales verificadas

## L04 — PENDIENTE
- capturas verificadas de interfaz
- rúbrica docente final

## L05 — PENDIENTE
- ejemplos documentados con fuentes y fechas
- revisión de referencias vigentes

## L06 — PENDIENTE
- guía de privacidad de cada proveedor
- validación normativa/jurídica independiente

## L07 — PENDIENTE
- tabla de tareas y ejemplos ampliados
- demostraciones de proveedores verificadas
- autoevaluación docente

## L08 — PENDIENTE
- ejemplo resuelto completo con datos ficticios
- rúbrica docente final
- capturas verificadas del proceso

No se simulan pantallas de proveedores. Los diagramas editables son esquemas pedagógicos, no evidencia de funcionalidades. No se han escrito claves de las evaluaciones. No reutilizar colores provisionales como códigos HEX oficiales.
