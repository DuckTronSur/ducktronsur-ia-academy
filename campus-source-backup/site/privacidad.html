Mi Campus

Política de privacidad

Última actualización: 12/10/2026

Responsable

DuckTronSur IA Academy. Contacto: ducktronsur@encuentraelsur.com.

Datos que tratamos

Cuando creas una cuenta podemos tratar tu correo electrónico, nombre visible, rutas y lecciones completadas, proyectos, entregas y enlaces de evidencia que decidas guardar.

Para qué se usan

Se usan para permitir el acceso, recuperar la cuenta, mostrar el progreso, guardar entregas y mejorar el funcionamiento del Campus.

Contraseñas y seguridad

Las contraseñas no se muestran ni se guardan en documentos del proyecto. Aplicamos controles de acceso y políticas RLS para separar los datos de cada usuario.

Servicios utilizados

El Campus se aloja en Cloudflare Pages, la autenticación y los datos se gestionan con Supabase y los correos de autenticación se envían mediante Brevo. WhatsApp se abre como servicio externo cuando eliges unirte a la comunidad.

Conservación y eliminación

Conservamos los datos mientras mantengas tu cuenta o mientras sean necesarios para prestar el servicio. Puedes solicitar acceso, rectificación o eliminación escribiendo al contacto indicado.

Cambios

Actualizaremos esta página si cambia el funcionamiento o el tratamiento de datos.
